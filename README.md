# App Combustível

App em Flutter para saber qual combustível compensa mais: Álcool ou Gasolina.

## Regra dos 70%

Divide o preço do álcool pelo preço da gasolina:

- menor que 0,70 → abasteça com **Álcool**
- maior que 0,70 → abasteça com **Gasolina**

## Como rodar

```bash
flutter create .
flutter run
```

## Calcule a Média (Exercício 3)

O botão **Calcule a Média** calcula a média dos valores digitados
(álcool + gasolina, dividido por 2) e mostra o resultado na mesma tela.
